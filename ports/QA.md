# 跨平台功能回归

测试入口随 `multiplatform` 保存，统一 CI 对同一提交执行测试和打包。以下覆盖自动化能够复现的流程；通过状态以对应 Actions 运行的步骤、日志和 xcresult 为准。

| 层级 | 覆盖 |
| --- | --- |
| 共享与桌面单元测试 | 18 项：歌词时序 / 重叠人声、队列、搜索、备份校验、排序过滤、路径 / Range / 认证、HTTP 错误与重定向、WAV 元数据 / 侧车歌词 / 重启、离线下载与取消、AI 两协议、并发存储 |
| Linux Electron 实际应用 | 原生导入 / 文件夹 / 去重；分组 / 搜索 / 排序 / 筛选；实际 Web Audio 信号、EQ / 倍速 / 拖动进度；暂停切歌 / 队列编辑；收藏；歌单成员 / 排序 / 重命名 / JSON 与 M3U 导出 / JSON 导入；TTML 翻译 / 罗马音 / 背景人声；打轴 / 撤销重做 / 外置歌词 / SVG / 弹窗背景与触摸期间重排；封面与显示信息；备份恢复；完整进程重启；播放记录；服务端刷新 / 流播放 / 封面 / 歌词 / 下载、断网播放及记录移除；本地 MV；文件丢失错误与恢复 |
| iOS 原生 XCTest | 10 项：首次空资料目录保存与重启；导入 / 内容去重 / 元数据 / 侧车歌词 / 重启 / 安全移除；独立 Keychain 账户读写与脱敏；路径与鉴权；WebDAV / 封面 / 错误 / 重定向；Emby 登录与 AI 两协议；Subsonic 原始下载 / 身份 / 离线原生播放；取消清理；原生进度 / 倍速 / EQ / 暂停切歌 / 队列 / 睡眠；自动切歌 / 单曲循环 / 播完暂停 / 计次 / 历史恢复 |
| iPhone WKWebView 界面 | 歌单创建与重启；收藏 / 搜索 / 歌单重命名删除；歌词编辑 / 撤销重做 / 信息修改与重启；实际原生 PCM 播放 / EQ / 进度 / 暂停切歌 / 队列 |
| iPad WKWebView 界面 | 原生 PCM 播放 / EQ / 进度 / 暂停切歌 / 队列与控件可达性 |

Linux 原生文件选择与导出对话框在测试进程内返回夹具路径，其余 IPC、音频 / 视频、文件写入与应用重启均使用真实实现。开发运行与打包后的 Linux 应用执行同一套回归。测试使用隔离的临时用户目录，不修改日常曲库。iOS 原生测试编译同一份生产 Swift 实现，使用临时目录和独立 Keychain 账户；每项界面测试有独立资料目录，同一用例重启保留资料，避免失败影响下一项。协议夹具只监听本机，不调用付费 AI；iPad 在 iPhone 功能测试失败时仍继续执行。界面播放夹具为 120 秒真实 PCM，避免慢速模拟器操作期间短曲目提前播完；原生自动切歌与队列结束测试仍使用短音频。

## 复现

```bash
cd ports
npm ci
npm test
npm run build
# Linux 需 Xvfb、FFmpeg，普通用户运行。
xvfb-run -a node desktop/smoke.mjs
```

iOS：在 macOS 执行 `npm run prepare:ios`，启动 `python3 scripts/fixture-server.py`，使用 Halcyon scheme 执行 Xcode Test。CI 分别上传 iPhone `smoke.xcresult`、iPad `ipad.xcresult`。

## 仍需人工环境验收

- 真机 Files / iCloud 选择器、外部文件授权、实际格式 / 大曲库性能。
- 锁屏与系统控制中心、电话中断、耳机 / 蓝牙 / AirPlay、长时间后台播放。
- 用户自己的 WebDAV / Navidrome / Emby 服务器，包括实际目录和分页边界。
- 正式安装包安装、签名 / 公证、发行版系统钥匙串；模拟器通过不替代真机与真实服务器验证。

本轮回归修复：离线远程歌曲移除时同时清理本地索引；浏览器媒体异常使用可读错误提示；iOS WebDAV 空路径使用配置根地址，修复首次目录浏览被误拒绝；手机表单文字至少 16px，避免 iPhone 输入自动缩放导致后续控件触摸定位偏移；点击输入框外的页面内容收起键盘，避免输入辅助栏遮住操作按钮。资料目录在首次写入前创建，空曲库也能保存歌单；弹窗仅在按下与点击都位于背景时关闭，避免键盘收起后的重排误关闭歌词编辑器。模拟器测试采用临时签名与测试权限，实际检查 Keychain；真机 Release 仍需用户自己的开发者签名。
